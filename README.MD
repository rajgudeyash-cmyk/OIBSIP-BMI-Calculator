Introduction

The BMI Calculator is a Python-based application that calculates Body Mass Index using a person's weight and height.

This project includes both a command-line version and an additional web-based version.

Features

- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates BMI automatically.
- Displays BMI rounded to two decimal places.
- Classifies BMI into the specified categories.
- Validates numeric inputs.
- Rejects zero and negative values.
- Provides helpful error messages.
- Includes an additional mobile-friendly web interface.

BMI Formula

BMI = Weight (kg) / Height (m)²

BMI Categories

According to the project requirements:

- Underweight: Below 18.5
- Normal: 18.5–24.9
- Overweight: 25–29.9
- Obese: 30 or above

Note: These are standard adult reference categories and are not intended for assessing teenagers' health.

How to Run

Command-Line Version

1. Open the project in Python or Pydroid 3.
2. Run "bmi_calculator.py".
3. Enter weight and height when prompted.
4. View the calculated BMI and category.

Web Version

1. Install Python.

2. Install dependencies:
   
   "pip install -r requirements.txt"

3. Run:
   
   "python bmi_web.py"

4. Open your browser and visit:
   
   "http://127.0.0.1:5000"
