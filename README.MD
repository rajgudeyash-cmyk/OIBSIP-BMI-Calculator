Introduction

The BMI Calculator is a Python-based application that calculates Body Mass Index using weight and height. It includes both a command-line version and a web-based version.

Features

- Simple and user-friendly interface.
- Weight and height input fields.
- Automatic BMI calculation.
- Result displayed on the webpage.
- Input validation and error handling.
- Mobile-friendly design.

Technologies Used

- Python
- Flask
- HTML
- CSS
- Pydroid 3

Project Files

- "bmi_calculator.py" – Command-line BMI Calculator.
- "bmi_web.py" – Flask web application.
- "requirements.txt" – Required Python dependencies.
- "README.md" – Project documentation.

How to Run

1. Install Python.

2. Install dependencies:
   
   "pip install -r requirements.txt"

3. Run the web application:
   
   "python bmi_web.py"

4. Open your browser and visit:
   
   "http://127.0.0.1:5000"

BMI Formula

BMI = Weight (kg) / Height (m)²

BMI Categories

The application demonstrates standard adult BMI reference categories. These are not intended for assessing teenagers' health.
