Introduction

The BMI Calculator is a Python application that calculates Body Mass Index using the user's weight and height.

Objective

To develop a simple BMI Calculator using Python and understand basic calculations, conditional statements, and exception handling.

Formula

BMI = Weight (kg) / Height (m)²

Features

- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates BMI automatically.
- Displays BMI rounded to two decimal places.
- Classifies BMI into standard adult categories.
- Handles invalid numeric input.
- Rejects zero and negative values.

BMI Categories

- Underweight: Below 18.5
- Normal: 18.5–24.9
- Overweight: 25–29.9
- Obese: 30 or above

Note: These categories are adult reference ranges and are not intended for interpreting BMI in teenagers.

Technologies Used

- Python
- Pydroid 3

How to Run

1. Install Python or open Pydroid 3.
2. Open "bmi_calculator.py".
3. Run the program.
4. Enter your weight and height.
5. View the calculated BMI and category.
